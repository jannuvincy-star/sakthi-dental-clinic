# 🦷 Sakthi Dental Clinic — Website

A modern, responsive website designed for **Sakthi Dental Clinic**, providing a clean, user-friendly online experience for patients to explore dental services, learn about the clinic, and get in touch.

## 🌐 Project Overview

The Sakthi Dental Clinic website is developed to establish a professional online presence for a dental clinic. It features a clean design, easy navigation, informative sections, and a responsive layout for desktop and mobile users.

## ✨ Features

- Responsive and modern UI design
- Home page with clinic introduction
- About page
- Dental treatments and services
- Frequently Asked Questions (FAQs)
- Contact page
- Privacy Policy page
- Dentist profile section
- Interactive elements using JavaScript
- Image integration
- User-friendly navigation

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts
