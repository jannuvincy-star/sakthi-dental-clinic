SAKTHI DENTAL CLINIC - SHADOWFOX INTERMEDIATE PROJECT

HOW TO RUN
1. Extract this ZIP file.
2. Open the sakthi-dental-clinic folder in VS Code.
3. Open index.html in your browser, or use the VS Code Live Server extension.
4. Keep the css and js folders beside the HTML files.

PAGES
- index.html: Home page
- about.html: About the clinic and doctors
- treatments.html: 15 treatment descriptions
- faqs.html: Expandable frequently asked questions
- contact.html: Responsive contact form with front-end validation
- privacy.html: Privacy policy

CUSTOMIZATION
- Replace the illustrated emoji hero/doctor placeholders with approved clinic images from the provided Google Drive folder.
- Update any clinic details with the coordinator/client's confirmed information.
- Social links are placeholders and should be replaced with official clinic profile URLs.
- The contact form currently validates in the browser only. It does not send, email, or store data; a backend or form service is required for that.

TECHNOLOGIES
HTML5, CSS3, JavaScript. Google Fonts are loaded online; system fonts are used as fallback.
